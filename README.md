# HAN campusatelier

Dashboard met 33 richtingen: 25 voor verschillende campusplekken en acht voor de bovenkant van de fietsenstalling. Bekijk de openbare website: https://luna-uyt.github.io/han-campus-ideeen-dashboard/ . Lokaal openen kan ook via index.html of OPEN_DASHBOARD.cmd. Geen installatie nodig.

De campusbrede verkenning combineert vijftien eerdere richtingen met tien nieuwe. Elk concept heeft een unieke illustratie, drie toegelichte effectscores, voor- en nadelen, voorwaarden, resultaatindicatoren en mogelijke plektypen. Een plektype is geen bevestiging van geschiktheid van een specifieke HAN-locatie.

Zoeken, filteren op thema en type plek, maximaal drie richtingen vergelijken, favorieten en CSV-export. Alle inhoud en illustraties werken lokaal. Favorieten worden alleen in de eigen browser bewaard.

Bronnen en beoordeling zijn in het dashboard toegelicht. Scores zijn kwalitatieve ontwerpanalyse, geen metingen of officiële HAN-scores. De afbeeldingen zijn principeschetsen, geen uitvoeringsontwerpen.

## Repository gebruiken

Download via Code → Download ZIP en pak het bestand uit. Open daarna index.html of OPEN_DASHBOARD.cmd. Alle benodigde illustraties zijn meegeleverd. De site gebruikt geen buildstap, serveropslag of externe afhankelijkheden. GitHub Pages publiceert de main-branch.
